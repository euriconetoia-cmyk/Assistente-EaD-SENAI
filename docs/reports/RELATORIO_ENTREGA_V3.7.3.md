# Relatório de entrega do Assistente EaD SENAI 3.7.3

## Funcionalidade

O download para correção com IA passa a gerar um pacote mestre do curso. Cada atividade é armazenada em uma pasta independente e numerada.

Cada pasta contém:

- envios dos alunos;
- enunciado da atividade;
- critérios ou rubrica;
- dados da atividade e nota máxima;
- manifesto individual;
- agente corretor;
- instruções de utilização.

A raiz contém um arquivo de orientação e o manifesto geral de todas as atividades incluídas.

## Proteção de tamanho

O pacote permanece único até aproximadamente 450 MB. Quando o volume excede esse limite, a extensão cria partes numeradas. Uma atividade nunca é fragmentada entre arquivos diferentes.
