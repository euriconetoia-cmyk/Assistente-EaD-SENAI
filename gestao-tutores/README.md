# Protótipo arquivado da Gestão de Tutores

Esta pasta permanece somente como referência histórica da primeira prova de conceito da dashboard.

A implementação oficial e ativa da Gestão de Tutores está em:

`gestao-tutores-extension/`

O protótipo com dados simulados foi removido nesta versão para evitar manutenção duplicada, divergência de regras e dúvida sobre qual implementação deve ser validada.

Para desenvolvimento, testes, instalação e documentação, utilize exclusivamente `gestao-tutores-extension/`.
